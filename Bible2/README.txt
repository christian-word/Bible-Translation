Читалка Библии: 5 переводов, параллельный просмотр, поиск, закладки.

Как открыть
- На компьютере: в этой папке запустите любой локальный веб-сервер и откройте адрес в браузере,
  например:  python -m http.server 8000   →   http://localhost:8000
  (двойной щелчок по index.html не подойдёт: браузер блокирует чтение файлов из папки data).
- По ссылке с телефона: загрузите всю папку на хостинг (GitHub Pages, Netlify и т.п.) и откройте адрес сайта.
  В браузере телефона можно выбрать «Добавить на главный экран»: читалка будет работать и без интернета
  для уже открытых книг.

Состав: index.html, sw.js, manifest.webmanifest, icon-*.png, data/ (тексты и таблица соответствия нумерации).
Если обновите файлы в data, поменяйте номер версии в начале sw.js (const V), чтобы телефон забрал новые.
